# Experiments

Everything here was tried on top of the final method and dropped, but kept for reference.

- `solfire` (`solfire.main`) is the final method only and never imports this package.
- `solfire-lab` (`solfire.experiments.main`) is the same command line with these experiments

Scores are pooled out-of-fold PQ, comparable only within a row. The `results.csv` of a sweep holds
per-fold numbers, which mislead on their own.

| Experiment                                                                          | How to run it                                                                                                                     | Sweep specs                       | Outcome                                                                         |

## Training variants


| Variant                                                                                                                           | Sweep specs                                                                  | Outcome                                                                             |
|-----------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------|-------------------------------------------------------------------------------------|
| ImageNet ResNet34 U-Net++ (the first baseline family)                                                                             | `cv5.json`                                                                   | Replaced by the SSL-pretrained ResNet34                                             |
| Encoder and decoder choice: ResNet34, EfficientNet-B3, MiT-B2, ConvNeXt-T, RegNetY-016; U-Net vs U-Net++; ImageNet vs random init | `pretrained.json`                                                            | Picked the ResNet34, MiT-B2 and HRNet-W32 families                                  |
| EfficientNet-B3 family                                                                                                            | `cv5_effb3.json`, `finetune_effb3.json`, `lovasz60_effb3.json`               | Dropped                                                                             |
| Soft targets (`mean`) vs one sample per record (`each`), crops per image                                                          | `targets.json`                                                               | `mean` kept                                                                         |
| 1024 crops                                                                                                                        | `cv5_1024.json`, `finetune_1024.json`                                        | 0.4458 vs 0.4503                                                                    |
| Lovász from the first epoch, 60 epochs                                                                                            | `lovasz60*.json`                                                             | Worse than the 8-epoch Lovász fine-tune                                             |
| Longer Lovász fine-tune (16 epochs)                                                                                               | `finetune_long*.json`                                                        | cv15 0.4589 vs 0.4594: 8 epochs is enough                                           |
| Second seeds of the fine-tuned models                                                                                             | `finetune_seed2.json`, `finetune_mitb2_seed2.json`                           | Ensemble plateau around 0.455 (cv30-seeds-mitb2x2 0.4554)                           |
| 2× zoom for ResNet34 and MiT-B2                                                                                                   | `finetune_zoom.json`, `finetune_zoom_mitb2.json`                             | Only the HRNet zoom model was kept                                                  |
| Fine-tune of the distilled student                                                                                                | `finetune_distill.json`                                                      | See distillation above                                                              |
| Control: the Lovász fine-tunes trained without calibration, final epoch vs the validation-picked one                              | `finetune_last.json`, `finetune_last_hrnet.json`, `finetune_last_mitb2.json` | Final epoch 0.4602 vs picked 0.4593, so the full-data models keep their final epoch |
